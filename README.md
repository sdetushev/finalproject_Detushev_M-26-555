# Валютный кошелёк

Консольное приложение на Python для управления валютным кошельком.

Проект разрабатывается в рамках итоговой работы по Python. Приложение будет поддерживать операции с валютами и хранение данных с использованием объектно-ориентированного программирования.

## Используемые технологии

- **Python 3.12+** — основной язык программирования.
- **uv** — управление зависимостями и сборка Python-пакета.
- **PrettyTable** — форматированный вывод данных.
- **Ruff** — проверка и форматирование Python-кода.
- **Git** — контроль версий.

## Установка

Для работы с проектом необходимы Python 3.12 или новее, а также `uv`.

Установка зависимостей:

```bash
make install
```

Альтернативный способ:

```bash
uv sync
```

## Запуск

Запуск приложения:

```bash
make run
```

Альтернативный способ:

```bash
uv run wallet
```

## Доступные команды

После запуска приложения доступны следующие команды:

| Команда | Назначение |
|---|---|
| `register` | Регистрация нового пользователя |
| `login` | Авторизация пользователя |
| `show-portfolio` | Просмотр балансов и оценочной стоимости портфеля |
| `buy` | Покупка виртуальной валюты |
| `sell` | Продажа виртуальной валюты |
| `get-rate` | Получение курса валютной пары |
| `help` | Справка по командам |
| `exit` | Завершение приложения |

Пример работы с приложением:

```text
register --username alice --password 1234
login --username alice --password 1234
buy --currency BTC --amount 0.05
show-portfolio
sell --currency BTC --amount 0.01
get-rate --from BTC --to USD
exit
```

Торговые операции и просмотр портфеля требуют авторизации.
Команда `get-rate` доступна без авторизации.

## Модель торговли

В проекте используется упрощённая модель симуляции торговли валютами.

- При регистрации создаётся пустой портфель.
- Команда `buy` увеличивает баланс выбранной валюты. Если кошелёк
  отсутствует, он создаётся автоматически.
- Команда `sell` уменьшает баланс выбранной валюты. При недостатке
  средств возникает `InsufficientFundsError`.
- Списание и начисление USD при торговых операциях не выполняются.
- Курсы валют используются для расчёта оценочной стоимости
  операций и портфеля.

Начальный баланс и отдельная команда пополнения не предусмотрены.

## Получение валютных курсов

Команда `get-rate` позволяет получить курс одной валюты
относительно другой.

Примеры:

```bash
get-rate --from BTC --to USD
get-rate --from USD --to EUR
get-rate --from EUR --to RUB
```

Курсы рассчитываются через USD и сохраняются в `data/rates.json`.

На текущем этапе используются фиксированные котировки
от 5 ноября 2026 года. Они служат временным источником
данных и не обновляются в реальном времени.

Для каждой валютной пары сохраняются курс, источник,
дата снимка котировок и время записи в JSON.
