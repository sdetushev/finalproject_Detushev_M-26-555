# Валютный кошелёк

Консольное приложение на Python для управления валютным кошельком.

Проект разрабатывается в рамках итоговой работы по Python. Приложение будет поддерживать операции с валютами и хранение данных с использованием объектно-ориентированного программирования.

## Используемые технологии

- **Python 3.12+** — основной язык программирования.
- **uv** — управление зависимостями и сборка Python-пакета.
- **PrettyTable** — форматированный вывод данных.
- **Ruff** — проверка и форматирование Python-кода.
- **Git** — контроль версий.

## Установка

Для работы с проектом необходимы Python 3.12 или новее, а также `uv`.

Установка зависимостей:

```bash
make install
```

Альтернативный способ:

```bash
uv sync
```

## Запуск

Запуск приложения:

```bash
make run
```

Альтернативный способ:

```bash
uv run wallet
```

## Проверка качества кода

Проверка кода с помощью Ruff:

```bash
make lint
```

Проверка форматирования:

```bash
make format-check
```

Автоматическое форматирование:

```bash
make format
```

## Сборка пакета

```bash
make build
```

Результаты сборки сохраняются в каталоге `dist/`.

## Состояние проекта

На текущем этапе реализованы:

- Базовая структура Python-пакета.
- Управление зависимостями через `uv`.
- Точка входа консольного приложения `wallet`.
- Проверка и форматирование кода с помощью Ruff.
- Автоматизация основных команд через `Makefile`.

Основная функциональность валютного кошелька находится в разработке. По мере выполнения следующих этапов документация будет дополняться.
